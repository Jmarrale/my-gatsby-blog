Your roadmap — learn as you go

  1. Play with it

    Open the app and just use it: add a student, log a lesson, mark it completed, record a payment, open a student's Billing tab and print a statement. Break things freely — the reset button brings the samples back.

  2. Get two accounts

    Install a password manager (Bitwarden is free) and create a GitHub account. Save both logins in the password manager. That's the whole setup for now.

  3. Meet Claude Code — your teacher

    Open claude.ai/code, connect it to the project, and ask it to teach you. This is how you become technical — by asking, not studying. Start with:

    Explain what this project does and how the "app" folder is organized, like I'm brand new to coding.

  4. Read three short things

    Have Claude Code walk you through app/START-HERE.md, then app/docs/OWNERS_GUIDE.md, then the small, friendly file app/src/lib/billing.ts (the money math) with its test right beside it. Ask "what does this line do?" whenever you're curious.

  5. Make your first tiny change

    A safe, satisfying first edit — rename the app. Ask Claude Code:

    In src/brand.ts, change the name to my studio's name, then show me the app with the change.

  6. Go live for real

    When you're ready for real students, follow the Go-Live Checklist — it sets up your private login and cloud storage so your data is saved and backed up. Do it with a hand from a techy friend, or ask Claude Code: "Walk me through the handoff checklist one step at a time."

  7. Put it on your phone

    Open the live app in Safari → Share → Add to Home Screen. Now it opens like any other app on your iPhone.

  8. Grow it

    Once you're comfortable, dream bigger with Claude Code: lesson reminders, your own belt curriculum, charts of attendance and income — or building the real App Store version. You'll know enough to steer it.

A few honest notes

  • Costs: hosting is free for one person. The cloud database is free too, but "sleeps" after about a week idle (loads slowly until it wakes) — a paid tier (~$25/mo) removes that, and it's optional.
  • The iPhone App Store version would need a Mac and an Apple Developer account ($99/year). The home-screen app costs nothing.
  • Changing the code takes a developer — or you, leveling up with Claude Code. That's the whole point: start by using it, end up owning it.
